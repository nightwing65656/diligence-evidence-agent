# Security Policy

## Supported scope
This repository is an analyst-support prototype, not a production investment platform.

## Reporting a vulnerability
Please report vulnerabilities privately to the repository owner before public disclosure.

## Security priorities
- prompt injection resistance
- tool permission boundaries
- secrets protection
- source integrity
- reproducible calculations
- evidence tampering detection

## Non-goals
This public repository does not expose production credentials, trading systems, or customer data.
